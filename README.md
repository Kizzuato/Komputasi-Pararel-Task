Project Overview

This project demonstrates the fundamental differences between Serial Computing and Parallel Computing based on the course materials. The implementation compares a sequential approach with a parallel approach using Python's multiprocessing capabilities.

Key Concepts Applied

    - Serial Computing (SISD): Executes instructions one after another using a single processor or core.
    - Parallel Computing (MIMD): Splits a problem into multiple tasks that run simultaneously across different CPU cores.
    - Flynn’s Taxonomy: Classification of computer architecture based on Instruction and Data streams.
    - Performance Bottleneck: Demonstrating how parallelization can overcome limits in linear processing

File Structure

    MySequentialProgram.py: Implements a sequential loop

    MyPararelProgram: Implements process-based parallelization

    Mycomparation.py: A master script that executes both programs and compares their execution time.
